# PDF Shrinker

A free PDF compressor that runs **100% in your browser** — your files never leave your device.

**Live site:** https://bismark57.github.io/pdf-shrinker/

## Features

- Three compression levels, plus optional grayscale for maximum shrinkage
- Structure-preserving optimization mode (keeps text selectable and searchable)
- Before/after file size comparison with live progress feedback
- No uploads, no accounts, no tracking — everything happens locally

## How it works

Drop a PDF onto the page, pick a compression level, and download the smaller file.
Image-heavy PDFs (scans, exports with embedded photos) shrink the most: the
optimizer re-encodes images at lower quality/resolution and strips unneeded
metadata.

## Run it locally

Just open `index.html` in any modern browser — no build step, no server needed.
